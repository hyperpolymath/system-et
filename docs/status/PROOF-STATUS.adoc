== The wager experiment (verified by `./scripts/check-proofs.sh agda`)

This track is an experiment. It adds no ET obligation and it changes no ET
status. A new obligation needs an ADR from the repository owner.

The experiment decides, for a defined fragment, whether grades,
conversion-only equality and tropes can replace the coercions and roles of
System FC. Its own status file is
`verification/proofs/agda/Wager/VERDICT.adoc`. The headline statements are
types in `verification/proofs/agda/Wager/Statements.agda`.

All items below compile under Agda 2.8.0 with `--cubical --safe` and
`agda/cubical` v0.9 (pins in `verification/proofs/agda/Wager/TOOLCHAIN.adoc`).
There is no `postulate`. The library forces `--guardedness` on each file, and
no file uses coinduction. One warning class is silenced
(`UnsupportedIndexedMatch`); `DESIGN-CHOICES.adoc` gives the reason.

|===

| *Proven* for the experiment calculus. This is not the ET-2 calculus, and

| 4

  `t7-conservative` : the erasure of the proofs in casts is sound; closed
  evidence exists exactly for convertible types; a local equality
  assumption is a variable at the grade `0`
| Part 1 *Proven*. It excludes a translation that keeps the erased type
  and the erased term, and no other translation.
  Part 2 *Proven* for a signature that has an identity family (one such
  signature is built). The extension has 1 new rule and 1 new term former.
  The owner decides if it is inside the wager
