= systemet — thin session journal
:updated: 2026-11-10

What the next agent or human needs to resume work, and nothing that can be
derived. This is the STATE v2 thin journal
(`1-formats/templates/STATE.a2ml.v2.spec.adoc` in `standards`: phase, blockers,
last action, next action), written as AsciiDoc because A2ML is retired.

STATE v1 is archived at `.machine_readable/archive/state-v1.a2ml` (2026-11-10,
`state-v1-decision`, option B), and nothing in it is current. This file replaces
its journal sections. The lifecycle and maturity it carried are in the repo deed,
`systemet_chora.deed`.

Kept elsewhere, on purpose: milestones in `ROADMAP.adoc`, history in the git
log, evidence and the completion census in `PROOF-STATUS.adoc`, task lists in
the GitHub issues.

phase::
implementation. The mechanized core is in place: the L2 grade algebras (ET-4,
ET-5) and L1 conversion for the β-fragment of the core calculus (ET-1, ET-2).
The η extension, the gates beyond L2, tropes and TEA erasure (ET-14) are open.
Census, with its denominator: 2 of 15 ET obligations done and 2 in progress
(`docs/status/PROOF-STATUS.adoc`).

last_action::
Finished the wager experiment in Cubical Agda: stages 5 to 7 and the final
verdict (#89, 2026-11-10). W does not hold as written. It holds for the
fragment with 2 additions: trope states with an index, and, for a whole
program, a grade algebra in which the grade 𝟙 is unrestricted.

next_action::
Land the η-long normalizer `nfE` (issue #32). It is blocked on an `adjWkv`
weakening-exchange lemma (`docs/status/PROOF-STATUS.adoc`).

session_marker::
next_action taken from PROOF-STATUS (open items) and STATE v1 (2026-07-29);
owner to confirm it is still the intended next step.

2026-11-10
