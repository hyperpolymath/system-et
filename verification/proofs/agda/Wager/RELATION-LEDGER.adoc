= Wager: relation ledger
Status: Stage 4. Each later stage adds its entries in the same commit as its rules.
:toc: left
:sectnums:

This file lists each judgement form and each relation of the target calculus.
The baseline is the list in `docs/theory/00-notation.adoc`: kinding, conversion, the function `nf`, graded typing, trope transition.

Each entry has one class:

[cols="1,4",options="header"]
|===
| Class | Meaning
| baseline | The form is in 00-notation and is used as written there.
| baseline, changed | The form is in 00-notation. This experiment changes it. The change is named.
| specification only | The relation is used in theorem statements. No typing or kinding rule uses it.
| proof-internal | The relation is used in proofs only. No rule and no statement uses it.
| ADDED | The relation is not in 00-notation, and a typing or kinding rule uses it.
| source | The relation belongs to the source calculus (the fragment of System FC). The target calculus does not have it. It does not count against the wager.
|===

An ADDED entry counts against the wager. *Stages 1, 2, 3 and 4 have no ADDED entry.*
The ledger has one "baseline, changed" entry (R1). The owner decides how it counts.

== Judgement forms of the target calculus

[cols="1,3,3,2,4",options="header"]
|===
| Id | Form (00-notation) | Agda identifier | Class | Notes

| R1
| `Γ ⊢ A : k` (kinding)
| `Ty Γ k` in `Wager.L1.Syntax` (simple kind, intrinsic) and `_⊢ᵏ_` in `Wager.L1.Kinding` (grades)
| baseline, changed
| The context of the kinding judgement is graded: `γ ⊢ᵏ A` has a usage vector γ for the type variables.
  The documents grade term contexts only. The task asks for this change (DC-1.3).
  The form is the same form. No new relation between types exists.

| R2
| `Γ ⊢ A ≡ B : k` (conversion)
| `DefEq` in `Wager.L1.Conversion`
| baseline
| β, equivalence, congruence, as in 02-l1-equality. No η.
  New rules of the same relation: the δ-rules of the signature primitives (DC-1.1). They are computation rules of total type-level functions.

| R3
| `nf(A)`
| `nf` in `Wager.L1.Eval`
| baseline
| A total function. `DefEq t u ↔ nf t ≡ nf u` is proved (`Wager.Proofs.l1-equality`).

| R4
| `Γ ⊢ᵣ t : A` (graded typing)
| `_▸_⊢_∶_` in `Wager.L2.Typing`
| baseline
| Declarative, with a subusage rule and a conversion rule.
  The only relation between types in a rule is `DefEq` (rule `t-conv`).

| R5
| `A@s ⟶ A@s'` (trope transition)
| The premise and the conclusion of rule `t-step`: `carrier o at from o` and `carrier o at to o`, from `Wager.L2.Signature.TSig`
| baseline
| It is not a separate inductive relation. The signature gives, for each operation, one carrier type and two states.
  The carrier type cannot change (DC-1.4). Thus an operation is never a cast between two different carrier types.
|===

== Other relations in the development

[cols="1,3,2,5",options="header"]
|===
| Id | Agda identifier | Class | Notes

| R6
| `_⟶_` and `Value` in `Wager.L2.Term`
| specification only
| One-step reduction of terms (call by value) and the values. T0 (preservation, progress) is stated with them.
  No typing or kinding rule uses them. 00-notation has no reduction relation.

| R7
| `_≤ᵘ_` in `Wager.L2.Usage`, `_≼ᵏ_` in `Wager.L1.Kinding`
| baseline
| The order `≤` of the grade algebra (03-l2-grades), pointwise on usage vectors. Rules `t-sub` and `k-sub` use it.
  It is a relation between grades, not between types.

| R8
| `SemEq`, `EnvEq` in `Wager.L1.Completeness`
| proof-internal
| Kripke partial equivalence on values, for the completeness of `nf`.

| R9
| `Rel`, `SubRel` in `Wager.L1.Soundness`
| proof-internal
| Kripke logical relation between terms and values, for the soundness of `nf`.

| R10
| `SubTyping` in `Wager.L2.Substitution`
| proof-internal
| Typing of a parallel substitution with a usage matrix. It is a family of R4 judgements.

| R11
| `_≈_` in `Wager.Role.RepEq` (Stage 2)
| specification only
| Representational equivalence on closed normal types: the least congruence that contains newtype unfolding.
  The statements of T2 and T4 use it. No typing rule and no kinding rule uses it.

| R12
| `R★` and `Valid` in `Wager.Role.Validity` (Stage 2)
| specification only
| `R★ ρ` is what an observer of the role ρ can tell apart: nothing (phantom), types up to `≈` (representational), types up to identity (nominal).
  `Valid` says that each constant and each primitive of a signature respects its declared grade.
  The statements of noninterference and of T2 use them. No rule uses them.

| R13
| `LR`, `EnvLR` in `Wager.Role.Noninterference` (Stage 2)
| proof-internal
| The logical relation on closed values, indexed by the role of the observer.
|===

== Relations of the source calculus and of the erased calculus (Stage 3)

Stage 3 defines the source calculus. It adds no rule and no relation to the target calculus.

[cols="1,3,2,5",options="header"]
|===
| Id | Agda identifier | Class | Notes

| R14
| `Co` in `Wager.FC.Coercion`
| source
| The coercion relation of System FC, at the three roles. `cast` and `coerce` use it at the role representational.
  The wager says that the target calculus does not need this relation. The target calculus does not have it.

| R15
| `STm` in `Wager.FC.Term`, `WellRoled` in `Wager.FC.Signature`
| source
| Typing of source terms (by construction), and the role check of a source signature.

| R16
| `_⊢_⇓_` and `_⊢ᵉ_∶_` in `Wager.Erased.Untyped`
| specification only
| Big-step evaluation of untyped terms, and typing of untyped terms with erased types.
  The statements of Stage 3 use them. No typing rule and no kinding rule of the target calculus uses them.

| R17
| `RelV` in `Wager.FC.RoleSoundness`
| proof-internal
| What a coercion at each role must keep: the nominal value (nominal), the erased type (representational), nothing (phantom).
|===

== Relations of the translation (Stage 4)

Stage 4 defines the translation. It adds no rule and no relation to the target calculus.
The translated terms use the rules of Stage 1 only: the rule `t-step` types each trope transition, and the rule `t-conv` types the translation of a nominal coercion.

[cols="1,3,2,5",options="header"]
|===
| Id | Agda identifier | Class | Notes

| R18
| `𝒱`, `𝒞`, `ℰ` and `FO` in `Wager.Erased.LogRel`
| specification only
| Observational equality of untyped values at an erased type (a logical relation), and the first-order types.
  The statements of T3 and of T5 use them. No typing rule and no kinding rule uses them.

| R19
| `Translation` and `TwoState` in `Wager.Trans.TwoState`
| specification only
| What a translation of types must keep, and the two-state form. The statement `No-Two-State-Translation` uses them.

| R20
| `TyTr`, `IsoTyped` in `Wager.Trans.Typing`; `CoRel`, `CoRelIso` in `Wager.Trans.Simulation`
| proof-internal
| A term transformer keeps typing, and a term transformer keeps the erased behaviour.
|===

`StateScheme` (`Wager.Trans.Scheme`) is data of the translation: an index type and a table. It is not a relation.

== What is absent

* The target calculus has no coercion relation and no cast judgement. The coercion relation `Co` (R14) is in the source calculus only. The translation of Stage 4 makes each representational coercion a term of the target, with no new judgement.
* Representational equivalence exists as "specification only" (R11). It is not a judgement of the calculus.
* There is no subtyping relation between types.
