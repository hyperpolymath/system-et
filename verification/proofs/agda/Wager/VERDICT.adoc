== Results of Stage 3: the source calculus

Stage 3 has no T number. It defines the source calculus of claim W, a small fragment of System FC with roles (`Wager.FC`, DC-3.1 to DC-3.6).
Its results are about the source calculus only. They are properties that Breitner et al. state for their calculus, checked here for this fragment.
This development has no formal comparison of the fragment with the calculus of the paper.

[cols="3,1,5",options="header"]
|===
| Statement (`Wager.Statements`) | Status | Evidence and reading

| `Source-Nominal-Soundness`
| PROVED
| `Wager.Proofs.source-nominal-soundness`. A nominal coercion relates two types with the same nominal value. This needs no role check.

| `Source-Role-Soundness`
| PROVED
| `Wager.Proofs.source-role-soundness`. In a signature that passes the role check, a representational coercion relates two types with the same erased type.

| `Cast-Vanishes`, `Coerce-Erases-To-Identity`
| PROVED
| `Wager.Proofs.cast-vanishes`, `Wager.Proofs.coerce-erases-to-identity`. Each proof is `refl`: erasure removes each cast, and `coerce` erases to `λx. x`.

| `Erasure-Preserves-Typing`
| PROVED
| `Wager.Proofs.erasure-preserves-typing`. In a signature that passes the role check, the erasure of a term of the type τ has the erased type of τ.

| `Classic-Rejected`
| PROVED
| `Wager.Proofs.classic-rejected`. The source role check rejects the declarations "representational" and "phantom" for the parameter of `T` in `newtype T a = MkT (F a)`.

| `Classic-Bad-Coercion`, `Classic-Unsound-If-Accepted`
| PROVED
| `Wager.Proofs.classic-bad-coercion`, `Wager.Proofs.classic-unsound-if-accepted`. With the wrong declaration, `T Age` and `T Int` are representationally equal.
  A closed term of the type Bool then exists whose erasure is a Char literal. The erased term evaluates to that literal and has no erased type Bool.

| `Classic-Nominal-Accepted`, `Classic-Nominal-No-Coercion`
| PROVED
| `Wager.Proofs.classic-nominal-accepted`, `Wager.Proofs.classic-nominal-no-coercion`. The check accepts the declaration "nominal".
  Then `Age` and `Int` are representationally equal, and `T Age` and `T Int` are not: the source calculus rejects `coerce : T Age → T Int`.
|===

The limits of the fragment are in DC-3.1 and DC-3.2. Two limits matter most for the strength of W:

* A type is closed, and a term has no type variable.
* The body of a newtype cannot mention a declared newtype.

Not proved in Stage 3: evaluation of a typed erased term gives a value of its erased type (DC-3.6).
Stage 4 proves a part of it: in a signature that passes the role check, the erasure of each closed source term evaluates to a value (`Wager.Proofs.t5-behaviour`).

=== The source program with no two-state translation

[source,haskell]
----
newtype Tag a = MkTag Int
type family G a where { G Int = Bool ; G Bool = Char }
type family F a where { F (Tag a) = G a }
----

`Tag Int` and `Tag Bool` have one representation, `Int`. A two-state translation gives them one target type, `Int@tag`.
The function `F` gives `Bool` on the first type and `Char` on the second type. A nominal coercion becomes conversion, so `Bool` and `Char` become convertible.
The source role check accepts this program (`Wager.Examples.Stage3.Role-Check.wr-rep`). The three declarations are written as Haskell with type families. This development did not run GHC on them.

The translation with the row scheme gives the two types two states of the carrier `Int`. The two target types are not convertible, and the phantom coercion between them is a typed term with two trope transitions (`Wager.Examples.Stage4.Coercions-In-Affine.tag-typed`, `tag-states-differ`).

== Answers of Stage 1

=== Are the laws enough for sums and `case`?

Yes, for the declarative judgement.
Rule `t-case` gives the two branches one usage vector, and rule `t-sub` raises each branch to that vector.
The rule has no join. T0 is proved with this rule.

The proofs of substitution and preservation do not use `le-antisym`: the name does not occur in the proof files of `Wager/L2`. This is a text search. Agda does not check it.
The module of progress takes the operations only (`GradeOps`), so Agda checks that progress uses no law.

A checker that computes a usage vector is a different matter.
For `case` it must find one vector that is above the two branch vectors.
The law set has no operation for this. This development has no such checker and proves nothing about one.

== Answers of Stage 2

=== Which role table is sound in systemet?

The question has three parts.

*Part 1: a signature that respects its grades.*
Noninterference holds for the lawful table and for the GHC table (`Wager.Proofs.noninterference`).
The proof does not use the law `a · 0 = 0`.
The two tables then differ in three points.

[cols="2,3,3",options="header"]
|===
| Point | Lawful table | GHC table

| Law set
| All 15 law fields. T0 applies.
| `a · 0 = 0` fails. The structure is not a grade algebra.

| A parameter that does not occur, under a nominal function
| The grade phantom is accepted.
| The grade phantom is rejected (`Wager.Proofs.ghc-rejects-unused-parameter`). The role inference of GHC gives phantom to a parameter that does not occur. This development did not run GHC.

| What the grade phantom gives
| Equal normal forms for all arguments (`t2-phantom`).
| Equivalent normal forms (`Wager.Examples.Stage2.GHC-Examples.ghc-phantom`). This development has no proof of equal normal forms for the GHC table.
|===

*Part 2: a generative constant with a parameter that is declared phantom (`Proxy`).*
With the lawful table such a signature does not respect its grades (`Wager.Proofs.phantom-constant-not-valid`). Agda did not check this sentence for the GHC table.
With the lawful table the result is unsound: kinding accepts the grade phantom for `λa. deep (Proxy a)`, and this function maps `Age` and `Int` to types that are not equivalent (`Wager.Proofs.lawful-unsound-with-phantom-constant`).
With the GHC table the same function is rejected at each grade below nominal (`Wager.Proofs.ghc-rejects-deep`).

*Part 3: the decision.*
The lawful table is the sound table for systemet, for a signature that satisfies `Valid`: each constant and each primitive respects its declared grade.
`Wager.Role.Lawful.valid-lawful` gives a sufficient condition with 2 parts: no generative constant has a phantom parameter, and each primitive has the grade nominal.
The first part alone is not proved to be sufficient, because `Valid` also has a condition on each primitive.
Conversion sees the argument of a generative constant, so the parameter is used. The grade `0` means "not used".
With `Proxy` declared representational, `Proxy Int` and `Proxy Bool` are not related by `≈` (finding F8).

The law set does not need a change.
The third finding that the task names, two notions of use, is a candidate for the phantom coercions (finding F9).
Stage 2 proved the laws of the candidate only. It did not prove that the candidate gives the phantom coercions back, and it did not prove that no smaller change exists.

| F1
| The Lean class `GradeAlgebra` has 15 law fields and one derived law (`zero_add`). The documents say 16 laws.

| F2
| The systemet order of `Affine` has `0 ≤ ω` and `1 ≤ ω`, and `0` and `1` are not comparable.
  With this order a binder of grade `1` that is not used is rejected (`Wager.Examples.Stage1.T0-Affine.drop-rejected`).

| F3
| T0 uses the law `a · 0 = 0` (`mul-zero`), in the product of a usage vector with a matrix.
  The GHC role table fails this law (T1), so T0 does not apply to it.

| F4
| The stock cubical v0.9 library forces `--guardedness` on each importer (DC-0.2).

| F5
| Resolved on 2026-11-10. The owner asked for the repository update, so `docs/status/PROOF-STATUS.adoc` now has the marker line for Agda and a section for the experiment.
  `scripts/check-proof-status.sh` passes. The proofs workflow has an `agda` job, so CI runs the Agda gate.

| F6
| Noninterference needs `a ≤ a + b`. This holds for roles, because `+` is the maximum. It is not one of the 15 law fields.
  It is false in `Affine` with the systemet order: `0 + 1` is `1`, and `0 ≤ 1` is false (`Wager.Examples.Stage4.Coercions-In-Affine.affine-not-unrestricted`).

| F7
| The signature of Stage 2 with `Proxy` declared phantom does not respect its grades (`Wager.Proofs.phantom-constant-not-valid`).
  A nominal observer tells `Proxy Int` from `Proxy Bool`.
  The same argument applies to each generative constant with a phantom parameter. Agda checked this one signature only.

| F8
| With `Proxy` declared representational the signature is valid, and `Proxy Age ≈ Proxy Int` holds.
  But `Proxy Int` and `Proxy Bool` are not related by `≈` (`Wager.Proofs.no-phantom-coercion`). In Haskell a phantom parameter allows a coercion between them. This development did not run GHC.
  This result is about the relation `≈` only. It does not show that no term of the target calculus can do this coercion.
  Stage 4 shows a related result (finding F12): with the row scheme, a phantom coercion between two instances of a source newtype is a typed term of the target.
  Stage 4 does not translate the constant `Proxy` of the Stage 2 signature. The question stays open for that signature.

| F9
| Two notions of use. A 4-point structure with a separate grade "absent" for `0` has all 15 law fields and the GHC rule `nominal · phantom = nominal` (`Wager.Proofs.role4-lawful`, `Wager.Proofs.role4-has-ghc-rule`).
  This is a candidate for the phantom coercions without a change of the law set. Stage 2 did not prove that it gives them back.
  It would need a larger `≈` (a constant with a phantom parameter ignores its argument) and a weaker phantom part of T2 (`≈` in place of `≡`). This development did not check these two points.
  Stage 2 proved the laws only. It did not build kinding or noninterference for this structure. The owner decides.

| F10
| The source calculus uses the GHC entry `nominal · phantom = nominal` in its congruence rule for a newtype (DC-3.3): a newtype is generative.
  `Tag Int` and `Tag Bool` are not nominally equal, though the parameter of `Tag` is phantom (`Wager.Examples.Stage3.Nominal-Soundness-Examples.tag-nominal-rejected`).
  A type-level function tells them apart (`f-sees-phantom` in the same module), and they are representationally equal (`Wager.Examples.Stage3.Role-Soundness-Examples.tag-co`).
  This is the source side of findings F7 and F8.

| F11
| Role inference of the source (`roleOf`) uses the lawful entry `nominal · phantom = phantom`: a parameter that does not occur below a type-level function is phantom. `Source-Role-Soundness` is proved with it.
  This is sound only because a body of this fragment cannot mention a declared newtype (DC-3.2). The fragment cannot declare `newtype N a = MkN (F (Tag a))`.
  For that body the lawful entry gives phantom, and example `f-sees-phantom` shows that phantom is wrong there. Stage 3 has no Agda proof about such a body.

| F12
| Two-state tropes are not enough for the signature `taggedS rep`: a newtype with a phantom parameter and a type-level function that looks at that parameter (`Wager.Proofs.no-two-state-translation`, in the sense of DC-4.8). Agda checked this one signature.
  One wrapped state for each row of function results is enough (`rowScheme`, T5).
  The phantom parameter is then in the name of the state. It is not a type argument of a constant, so findings F7 and F8 do not apply to it.
  The phantom coercion is two trope transitions: unwrap from one state, wrap to the other state.

| F13
| A source program has no usage discipline. Its translation is typed in each grade algebra in which the grade `𝟙` is unrestricted (DC-4.5). This development does not prove that the condition is necessary.
  The rules of Stage 1 bind the components of a pair and the variable of a `case` branch at the grade `𝟙`. In `Affine` the translation of the source function `λx. 5` has no type (`const-rejected`). Agda checked this one function.
  A translated coercion is different: it uses each variable one time, and it is typed in each grade algebra.

| F14
| After erasure a translated coercion is not the empty term. The trope transitions vanish, and the maps of functions, pairs and sums stay (`Wager.Examples.Stage4.Programs.prog-erased`).
  The coercion is observationally the identity (T3). By the definition of `eraseT`, a trope transition leaves no term, and a map of a function, of a pair or of a sum leaves a term.
  This development has no optimisation that removes such a map.

| F15
| In this fragment the result of a type-level function is a base type. For a signature with a finite number of base types and of type-level functions, a finite number of states for each newtype is then enough (DC-4.1). Agda did not check this sentence.
  A function that returns a part of its argument is outside the fragment, in the source and in the target. This development proves nothing about it.
