=== The source program with no two-state translation

[source,haskell]
----
newtype Tag a = MkTag Int
type family G a where { G Int = Bool ; G Bool = Char }
type family F a where { F (Tag a) = G a }
----

`Tag Int` and `Tag Bool` have one representation, `Int`. A two-state translation gives them one target type, `Int@tag`.
The function `F` gives `Bool` on the first type and `Char` on the second type. A nominal coercion becomes conversion, so `Bool` and `Char` become convertible.
The source role check accepts this program (`Wager.Examples.Stage3.Role-Check.wr-rep`). The three declarations are written as Haskell with type families. This development did not run GHC on them.

The translation with the row scheme gives the two types two states of the carrier `Int`. The two target types are not convertible, and the phantom coercion between them is a typed term with two trope transitions (`Wager.Examples.Stage4.Coercions-In-Affine.tag-typed`, `tag-states-differ`).

== Results of Stage 6, part 1: the separation

The first result is about the target calculus as it is (`Wager.L2.Erasure`):

* `erase-typed`: a typed target term erases to a term with a simple type, the erased type of its target type. This holds for each signature and each set of grade operations.
* `identity-one-type`: if a target term has the type `A → B` and erases to the identity function, then `A` and `B` have one erased type.

The reason is the rule `t-conv`: the target calculus has conversion and no other equality of types, and two convertible types have one normal form.

Checked examples (`Wager.Examples.Stage6`):

* The source program at two instances (`eval-at-int`, `eval-at-sum`). The erased text is the same at each instance (`one-erased-text`).
* The first branch runs: the erased program, applied to the constructor GI with the literal `ℓint`, gives that literal (`live-branch-runs`).
* Rejected in the source: with no assumption, `Int ~ Int + Int` has no evidence (`no-evidence-for-gb`), because a closed equality of the source calculus is the identity of types (`closed-equality-is-identity`).
* Rejected in the target, for the signature of Stage 5 and the one-point grade algebra: the instance of T7 (`no-target-term`), and the identity function at the type `Int → Int + Int` (`identity-rejected`).
* Accepted in the target with another type of the data, for the same signature and algebra: `other-typed` and `other-same-erasure`.

== Results of Stage 6, part 2: the identity type

The extension is the target with an identity family (`Wager/Identity`). It is in separate modules, and no definition of stages 1 to 5 changes.

The main lemma is `Wager.Identity.Soundness.fund`: for a typed term in two related environments, the reference program and the program with no evidence in its casts evaluate to related values.
The case of a cast uses the value of the evidence. The value is a literal of the base type `Id A B`. The family has no literal off the diagonal, so A and B are convertible, so they have one erased type.

*Totality.* `fund` shows that each closed typed term has a value in the reference program. The reference program evaluates the evidence of each cast. The erased program does not, and it has the same value. The erasure is thus sound because the evidence has a value (DC-6.7).

*The grade.* The proof of `fund` does not use the grade of the rule `t-cast`. A test with the grade `𝟙` in the rule shows this (`TOOLCHAIN.adoc`). The grade gives `t7-grade`: the usage of a cast is the usage of its payload.
This development has no semantics that counts resources, so no theorem joins the behaviour and the resource count.

Checked examples (`Wager.Examples.Stage6Identity`), for the signature of `Wager.Identity.Instance` with one base constant and one literal:

* Accepted: a cast along `rfl` (`cast-one-typed`). Its erasure is the literal alone (`cast-one-erased`), and the two programs give that literal (`cast-one-keep`, `cast-one-erase`, `cast-one-sound`).
* Rejected: no closed term is evidence that `Int` is `Int + Int` (`no-evidence`).
* Rejected: a cast with evidence that has no value (`stuck`). The erased program has a value (`stuck-erase`), the reference program has none (`stuck-keep`), and the term has no type (`stuck-untyped`). The typing hypothesis of `T7-Erasure` is thus needed.
* Accepted: the function `Id Int (Int + Int) → Int → Int + Int` (`assume-typed`). Its erasure is `λ e. λ x. x` (`assume-erased`). The same function is typed in the algebra `{0, 1, ω}`, with the assumption at the grade `0` (`AtAffine.assume-affine`).
* Accepted: the GADT program of part 1, with data that holds the evidence (`evalⁱ-typed`, for each closed type α, in the one-point grade algebra). It has one erased text for each α (`evalⁱ-erased`). At α := `Int`, on the first constructor, the erased program gives the literal (`gi-one-runs`, `gi-one-sound`).
* The limit: the erased type of the data has a component for the evidence (`data-holds-evidence`).

=== The trade of Stage 6

The task says: "Do not decide whether option 1 adds a relation. Describe the trade and leave the decision to the owner." This section gives the facts for the decision. It does not make the decision.

*The question.* Is the target with an identity family (part 2) inside the wager, which says that the target "uses only the judgement forms in `docs/theory/00-notation.adoc`"?

*What the target can do with no identity family (part 1).* It has conversion and no other equality of types. It cannot type the two branches of one GADT match in the direct way (`T7-Separation`, with the limits of DC-6.2 and DC-6.4).

*What the identity family gives (part 2).*

* A local equality assumption is a variable (`T7-Assumption`). A cast uses it. The GADT program has a typed form.
* The erasure of the proofs in casts is sound (`T7-Erasure`).
* No new equality between closed types: a closed term is evidence for `Id A B` exactly when A and B are convertible (`T7-Intro`, `T7-Canonicity`).

*What the identity family costs.*

* EQUALITY EVIDENCE IS A TERM. The judgement `γ ▸ Γ ⊢ⁱ e ∶ base (Id A B)` says that A and B are equal under the assumptions in Γ. An equality with assumptions is thus in the calculus, in the typing judgement.
* Under a binder, conversion does not use an assumption. A program must name a cast at each use. Two types that are equal by an assumption are not convertible.
* The signature must have the family. This is a hypothesis.
* Evidence is data at run time, apart from the evidence of a cast.
* An open term can have a false assumption. Its body then does not run in a closed typed program, as in System FC.

*Facts for the answer "no relation is added".*

* The count of new judgement forms is 0. The count of new type formers is 0. `Ty`, `DefEq` and `nf` do not change (`RULE-DIFF-LEDGER.adoc`).
* The family is a set of entries of a signature. DC-1.1 says that a later stage adds entries to a signature.
* The typing judgement has its form of 00-notation, with 1 more rule.

*Facts for the answer "a relation is added".*

* The new rule `t-cast` is not in 00-notation, and the term former `cast` is not in the term syntax of the target.
* The typing judgement at the types `base (Id A B)` is a relation between two types under assumptions. It has the same reading as the relation `Coˡ` of the source calculus of Stage 6 (R21), the coercion judgement with assumptions. Agda does not check a correspondence between the two.
* The doctrine of the repository says that the calculus keeps one primitive relation, and that equality is conversion. With the family, a second way to show that two types are equal exists inside a binder.

*What does not depend on the answer.* A local equality assumption is outside the fragment of claim W (newtypes, roles, `coerce`, total type-level functions). The results for W (T0 to T6) do not use the identity family.
== Results of Stage 7: the univalent cross-check

The stage is optional. The owner asked for it. Stages 1 to 5 were complete.

*The model* (`Wager.Univalent.Model`, DC-7.1). A closed type of the target of Stage 4 is a type of the cubical universe. A base constant is a type that the model gets as a parameter. A newtype instance is a wrapper `Box X` of the interpretation X of its content, and `unboxEquiv : Box X ≃ X` is an equivalence. A trope transition is thus an equivalence, and `ua unboxEquiv` is a path between the two types.

*The denotation* (DC-7.2). The development has no function from a typed term to an element of the model. The model is a realisability model: an untyped value, the result of an erased program, realises an element. A wrapper is not seen at run time.

*The result.* `pathOf wr γ` is a path between the interpretations of the two sides of a representational coercion γ (DC-7.3). The transformer that Stage 4 gives for γ denotes the function `transport (pathOf wr γ)`: on a term that evaluates to a realiser of x, the transformed term evaluates to a realiser of `transport (pathOf wr γ) x`.
The proof (`Wager.Univalent.CrossCheck.coI-den`) has the shape of the typing proof of Stage 4. At a newtype axiom it uses `uaβ`: transport along `ua unboxEquiv` is `unbox`.

*What the cross-check adds to T3.* T3 says that an erased coercion does not change the value at run time. Stage 7 says what the coercion does to the meaning of the value: it moves the element along a path of types. The two facts agree: the realiser stays, and the element is transported.

Checked examples (`Wager.Examples.Stage7`), for the signature `taggedS rep`, the row scheme and the one-point grade algebra, with `Int` as the natural numbers:

* `Int` is the type of natural numbers, and `Age` is a wrapper of it (`int-is-nat`, `age-is-box`).
* Accepted: the axiom `Age ~ Int`. Transport along its path gives 7 from `box 7`, by computation (`age-transport`). The literal realises `box 7` at `Age` (`age-literal`), and the coerced term evaluates to a realiser of the transported element (`age-coerced`). The coercion function is a closure that realises transport (`age-function`).
* Accepted: congruence below the newtype `Box`. Transport along the path gives `box (7 , 3)` from `box (box 7 , 3)`, by computation (`box-transport`).
* Rejected: a literal does not realise a function (`literal-not-function`), and the literal of the type `Bool` does not realise a number (`bool-not-number`).

== Overall result

*W does not hold as written. W holds for the fragment with 2 additions.*
The rule of the task says: W holds for the fragment only if T0 and T2 to T6 are PROVED, the relation ledger has no ADDED entry, and the rule-diff ledger is empty. T0, T3, T4 and T6 are PROVED. T2 and T5 are PROVED WITH CHANGE, so the rule is not met. The relation ledger has no ADDED entry, and the rule-diff ledger has no entry for the target calculus of stages 1 to 5.
The smallest addition that makes W true has 2 parts. (1) Trope states with an index: a newtype with a parameter gets one wrapped state for each index of a state scheme, in place of the 2 states of `07-tropes.adoc` (the change of T5). With 2 states, the program of `Wager.Proofs.no-two-state-translation` has no translation of types that keeps the 3 properties of DC-4.8. (2) For a whole program, a grade algebra in which the grade `𝟙` is unrestricted (`𝟘 ≤ 𝟙` and `𝟙 + 𝟙 ≤ 𝟙`), because System FC has no usage discipline. == Answers of Stage 1

=== Are the laws enough for sums and `case`?

Yes, for the declarative judgement.
Rule `t-case` gives the two branches one usage vector, and rule `t-sub` raises each branch to that vector.
The rule has no join. T0 is proved with this rule.

The proofs of substitution and preservation do not use `le-antisym`: the name does not occur in the proof files of `Wager/L2`. This is a text search. Agda does not check it.

== Answers of Stage 2

=== Which role table is sound in systemet?

The question has three parts.

*Part 1: a signature that respects its grades.*
Noninterference holds for the lawful table and for the GHC table (`Wager.Proofs.noninterference`).
The proof does not use the law `a · 0 = 0`.
The two tables then differ in three points.

[cols="2,3,3",options="header"]
|===
| Point | Lawful table | GHC table

| Law set
| All 15 law fields. T0 applies.
| `a · 0 = 0` fails. The structure is not a grade algebra.

| A parameter that does not occur, under a nominal function
| The grade phantom is accepted.
| The grade phantom is rejected (`Wager.Proofs.ghc-rejects-unused-parameter`). The role inference of GHC gives phantom to a parameter that does not occur. This development did not run GHC.

| What the grade phantom gives
| Equal normal forms for all arguments (`t2-phantom`).
| Equivalent normal forms (`Wager.Examples.Stage2.GHC-Examples.ghc-phantom`). This development has no proof of equal normal forms for the GHC table.
|===

*Part 2: a generative constant with a parameter that is declared phantom (`Proxy`).*
With the lawful table such a signature does not respect its grades (`Wager.Proofs.phantom-constant-not-valid`). Agda did not check this sentence for the GHC table.
With the lawful table the result is unsound: kinding accepts the grade phantom for `λa. deep (Proxy a)`, and this function maps `Age` and `Int` to types that are not equivalent (`Wager.Proofs.lawful-unsound-with-phantom-constant`).
With the GHC table the same function is rejected at each grade below nominal (`Wager.Proofs.ghc-rejects-deep`).

*Part 3: the decision.*
The lawful table is the sound table for systemet, for a signature that satisfies `Valid`: each constant and each primitive respects its declared grade.
`Wager.Role.Lawful.valid-lawful` gives a sufficient condition with 2 parts: no generative constant has a phantom parameter, and each primitive has the grade nominal.
The first part alone is not proved to be sufficient, because `Valid` also has a condition on each primitive.
Conversion sees the argument of a generative constant, so the parameter is used. The grade `0` means "not used".
With `Proxy` declared representational, `Proxy Int` and `Proxy Bool` are not related by `≈` (finding F8).

The law set does not need a change.
The third finding that the task names, two notions of use, is a candidate for the phantom coercions (finding F9).
Stage 2 proved the laws of the candidate only. It did not prove that the candidate gives the phantom coercions back, and it did not prove that no smaller change exists.
