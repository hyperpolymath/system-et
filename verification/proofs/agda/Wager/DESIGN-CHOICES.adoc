= Wager: design choices
Status: entries of Stage 0, Stage 1, Stage 2, Stage 3 and Stage 4.
:toc: left
:sectnums!:

This file records each choice that the systemet documents do not make.
A choice in this file is a choice of the experiment. It is not systemet doctrine.
Each entry has an identifier `DC-<stage>.<n>`, the choice, the reason, and the alternatives.

== Stage 0

[[DC-0.1]]
=== DC-0.1: Agda 2.8.0, not 2.8.0.1 or 2.8.0.2

*Choice.* The development uses Agda 2.8.0 and cubical v0.9.

*Reason.* The cubical compatibility table lists only `v2.8.0` for `v0.9`.
The patch releases 2.8.0.1 and 2.8.0.2 exist, but the table does not list them.

*Alternative.* Use 2.8.0.2. This is possible only after a test of the full library with it.

[[DC-0.2]]
=== DC-0.2: `--guardedness` in each file (accepted by the owner)

*Choice.* Each file has a second pragma line, `{-# OPTIONS --guardedness #-}`.
No file uses coinduction.

*Reason.* The stock cubical v0.9 library sets `--guardedness` for all of its modules.
Agda 2.8.0 then rejects an import from a module without the flag (`InfectiveImport`).
`TOOLCHAIN.adoc` has the evidence.
`--safe` accepts `--guardedness` when `--sized-types` is off.

*Conflict.* The task says: add `--guardedness` only in a file that needs coinduction.
The stock library makes that rule impossible to obey.

*Decision.* The owner accepted alternative 1 on 2026-11-10.
At the end of each stage a search for `coinductive` in `Wager/` checks the intent of the rule. The search found nothing at the end of Stage 1, of Stage 2, of Stage 3 and of Stage 4.

*Alternatives.*

. Keep the choice. Check the intent of the rule by a search for the keyword `coinductive` in `Wager/`.
. Use a copy of the library with `--guardedness` removed from its `flags:` line.
  A test showed that this works for the modules that this development needs.
  The cost: the library configuration is not the released one, and a reviewer needs the same copy.
. Use no library, only the Agda builtin cubical modules. This breaks the rule "use the cubical library".

[[DC-0.3]]
=== DC-0.3: `UnsupportedIndexedMatch` is silenced per file, with this reason

*Choice.* A file that matches on indexed syntax may have the line
`{-# OPTIONS -WnoUnsupportedIndexedMatch #-}`.
The line is put only in the files that need it. It is not put in `wager.agda-lib`.
No other warning is silenced.

*Reason.* The warning says that a definition does not compute when its argument is a transport.
It does not say that the definition is wrong, and `--safe` accepts it.
Syntax with intrinsic kinds gives this warning for most definitions.
Hundreds of copies of it hide the other warnings.

*Why a green result stays meaningful.* All theorems of this development are paths (propositional equalities) or type inhabitants.
If a proof needs a flagged function to compute on a transport, the proof does not type-check, and the gate fails.
In that case the proof uses an explicit path lemma (for example `substRefl` or path induction).

*Related rule.* Cubical Agda has no axiom K.
A match that needs K is an error, not a warning.
Thus the Lean proofs that use `castNf_diag` (an equality on `Δ = Δ` closed by `rfl`) cannot be copied directly.

*Alternative.* Leave the warning on. This is honest but makes the output hard to read.

*Audit at the end of Stage 4.* 35 of the 64 files have the line. A test of the 13 new files without the line found the warning in 6 of them. It found no other warning, and it found 2 new files that had the line and did not need it. The line was removed from them. The other 5 new files compile without a warning.

*Audit at the end of Stage 3.* 29 of the 51 files have the line. A test of the 10 new files without the line found the warning in each of the 6 new files that have the line. It found no other warning. The other 4 new files compile without a warning.

*Audit at the end of Stage 2.* 23 of the 41 files have the line. A test without the line found the warning in each of the 23 files, found no other warning, and found 2 new files that did not need the line.

*Audit at the end of Stage 1.* 18 of the 29 files have the line. A test without the line found the warning in each of the 18 files and found no other warning.
The test also found 2 files that had the line and did not need it. The line was removed from them.

[[DC-0.4]]
=== DC-0.4: a library file outside `Wager/`

*Choice.* Two files are outside `Wager/`: `verification/proofs/agda/wager.agda-lib` and `verification/proofs/agda/MANIFEST`.

*Reason.* `scripts/check-proofs.sh` reads the manifest from that path and starts Agda from that directory.
Agda needs the library file in the source root to find `cubical-0.9`.

[[DC-0.5]]
=== DC-0.5: identifier names that the danger scan accepts

*Choice.* No identifier contains the whole words `axiom`, `Axiom`, `admit`, `sorry` or `postulate`.
The coercion axioms of System FC get names that start with `ax`.

*Reason.* `scripts/scan-dangerous.sh` searches the code (not the comments) for these words.
A match fails the scan. The scan must stay meaningful, so the names avoid the words.

== Stage 1

[[DC-1.1]]
=== DC-1.1: the L1 language has a signature (accepted by the owner)

*Choice.* The L1 language is defined over a record `Sig` (`Wager.L1.Signature`). The signature has:

* two carrier types for grades: `KG` for kind arrows and `TG` for the object arrow and term binders;
* base constants of kind `★`;
* generative unary constants (`capp c A`), each with a parameter grade `cgrade c`;
* total inspection primitives (`papp p A`), each with a parameter grade `pgrade p` and a table.

A primitive looks at the head of its argument. On a base constant, an arrow, a product or a sum it gives a base constant.
On `capp c A` it gives a base constant, or it gives the argument `A` to another primitive.
The recursion is on the normal form, so each primitive is total.

*Reason.* Stage 2 needs newtypes and an inspection primitive. With a signature, Stage 2 adds entries, and the proof of `DefEq t u ↔ nf t ≡ nf u` is done one time.

*The Lean language as an instance.* The Lean language is the signature with base constants `ℕ`, no unary constant and no primitive.

*Limits.* A generative constant has one parameter of kind `★`. A primitive has one parameter of kind `★`, and its results are base constants.
A primitive cannot return a part of its argument.

[[DC-1.2]]
=== DC-1.2: `nf` by evaluation, not by hereditary substitution

*Choice.* `nf` evaluates a term in a Kripke model and reads the normal form back (`Wager.L1.Eval`).
A value of arrow kind is a pair of its normal form and its action on arguments. The normal forms are β-normal with no η-expansion.

*Reason.* The Lean proof closes casts on context equalities by `rfl` (UIP). Cubical Agda has no K.
Evaluation has no context cast. Each function is structurally recursive, so totality is by construction, as in the Lean development.

*Not proved here.* The Lean development proves stability (`nf_emb`: a normal form is a fixed point of `nf`). This development does not prove it. The equivalence does not need it.

[[DC-1.3]]
=== DC-1.3: grades on kind arrows, and a graded kinding judgement

*Choice.* A kind arrow is `k₁ ⇒[ g ] k₂`. The judgement `γ ⊢ᵏ A` (`Wager.L1.Kinding`) checks how a type uses its type variables.
The simple kind of a type is intrinsic. The term typing judgement has no graded-kinding premise.

*Reason.* The task asks for grades on kind arrows, because roles are on type parameters.
The current kernel and the documents grade term binders only. Thus this is a choice of the experiment.

*Consequence.* `RELATION-LEDGER.adoc` records kinding as "baseline, changed" (R1).

[[DC-1.4]]
=== DC-1.4: a trope state is a unary type constant, and the raw state is the bare type

*Choice.* `A@s` is `capp s A`. The raw state has no wrapper: it is the type `A`.
The term signature `TSig` gives each operation one closed carrier type and two states (`from`, `to`).
The typing rule `t-step` moves a term from `carrier o at from o` to `carrier o at to o`.

*Dynamics.* A transition to a state other than raw makes a value (`v-step`).
A transition to the raw state reduces to the raw value under the transitions (`β-strip`, `peel`).

*Reason.* Document 07 gives `A@s -> A@s'` and no dynamics. A newtype over a function type needs a raw value that is a function, or progress fails.

*Limit.* The carrier of an operation is a closed type.

[[DC-1.5]]
=== DC-1.5: the L2 rule table, and two grade algebras (the second accepted by the owner)

*Choice.* Document 03 leaves the rule table open. The rules follow the checker of the anytype kernel:
a graded arrow `arr q A B` (not a separate modality `□ᵣ`), a binder with a declared grade, and a pair whose components are bound at `𝟙`.
Added, as the task asks: sums, `case`, a subusage rule (`t-sub`) and a conversion rule (`t-conv`).
The judgement is declarative: it does not compute a usage vector.

*Two algebras.* Kind arrows have grades in `KG`. The object arrow and term binders have grades in `TG`. The two are separate parameters.

*Types of terms.* The type of a term is a closed type of kind `★`. Terms have no type variables.

*Reduction.* Call by value, left to right.

[[DC-1.6]]
=== DC-1.6: operations and laws are separate records, and `≤` is a type family

*Choice.* `GradeOps R` has the 5 operations. `GradeLaws ops` has the 15 law fields of the Lean class, in the same order. `GradeAlgebra R` has both.
`_≤_` has values in `Type`. The Lean class has `le` in `Prop`.

*Reason.* The judgements take `GradeOps` only. Stage 2 must examine structures that fail a law.
No proof of Stage 1 needs `≤` to be a proposition.

*Count of laws.* The Lean class has 15 law fields and derives `zero_add`. The documents say 16 laws. This development has the same 15 fields and the same derived law.

[[DC-1.7]]
=== DC-1.7: repository files outside `Wager/` (on the request of the owner)

*Context.* The task first said: do not push, and do not edit `docs/status/PROOF-STATUS.adoc`.
On 2026-11-10 the owner asked for the push and for the updates that put the repository in a consistent state.

*Choice.* These files outside `verification/proofs/agda/` changed:

* `docs/status/PROOF-STATUS.adoc`: the marker line for Agda, one summary row and one section for the experiment. The section says that the experiment claims no ET obligation.
* `.github/workflows/proofs.yml`: an `agda` job with pinned downloads.
* `verification/proofs/README.adoc`: the layout now shows the `agda/` directory.
* `Justfile`: the `test` recipe also runs the Agda gate.
* `CHANGELOG.adoc`: one entry.

*Not changed.* `docs/theory/OBLIGATIONS.adoc`, `AFFIRMATION.adoc` and each `.a2ml` file. A new obligation needs an ADR from the owner.

*Reason.* The drift gate compares `PROOF-STATUS.adoc` with the manifests, and the repository rule says that a gated proof must run in CI.

== Stage 2

[[DC-2.1]]
=== DC-2.1: representational equivalence is on closed normal types

*Choice.* `≈` (`Wager.Role.RepEq`) relates closed normal types of kind `★`.
It is the least congruence that contains newtype unfolding: `A@s ≈ A` when `s` is a newtype state.
A role signature (`RoleSig`) says which unary constants are newtype states (`isNewtype`).
For two types `A` and `B`, "A ≈ B" means `nf A ≈ nf B`.

*Reason.* The task states T2 on normal forms. On normal forms no rule for conversion is needed.

*Consequence.* The congruence rule holds for each constant, also for one that is not a newtype state.
`Proxy A ≈ Proxy B` thus holds exactly when `A ≈ B`.

[[DC-2.2]]
=== DC-2.2: observers, and the hypothesis `Valid` of T2

*Choice.* T2 is proved by a relation with an observer role. A nominal observer sees the identity of a type, a representational observer sees a type up to `≈`, a phantom observer sees nothing.
T2 has the hypothesis `Valid`: each constant and each primitive of the signature respects its declared grade.

*Reason.* The task says that the graded kind of a primitive is declared in the signature, not in a rule.
A declaration can be wrong. A theorem about kinding must then assume that the declarations are right.
`Wager.Role.Lawful.valid-lawful` gives a simple sufficient condition: no constant has the grade phantom, and each primitive has the grade nominal.

*Consequence.* `VERDICT.adoc` gives T2 the status "PROVED WITH CHANGE", class "signature primitive".

[[DC-2.3]]
=== DC-2.3: the composition table is a parameter of noninterference

*Choice.* `Wager.Role.Noninterference` takes a `RoleTable`: a composition with associativity, a right unit and monotonicity.
The lawful table and the GHC table are instances.

*Reason.* Step 3 of Stage 2 asks which table is sound. One proof for the two tables answers the question for both.
The proof also uses `a ≤ a + b`. This holds because `+` is the maximum. It is not one of the 15 law fields.

[[DC-2.4]]
=== DC-2.4: the concrete signature of Stage 2

*Choice.* `Wager.Role.Classic` has the base types Int, Bool, Char, Unit, the newtype state `age` (so `Int@age` is `Age`), the generative constant `proxy`, and two primitives.
`isAge` tells `Int@age` from `Int`. `deep` inspects the argument of `proxy` with `isAge`.
The declared grade of the parameter of `proxy` is a parameter of the signature.

*Reason.* The task asks for a test with a generative constant with an unused parameter, below a function that inspects its argument.
A primitive that inspects the head only cannot see below `proxy`. `deep` can, by the delegation of DC-1.1.

[[DC-2.5]]
=== DC-2.5: the 4-point role structure is a finding only

*Choice.* `Wager.Role.Role4` proves that a structure with a separate grade "absent" has all 15 law fields and the GHC rule.
Stage 2 does not build a kinding or a noninterference theorem on it.

*Reason.* T1 names a 3-point carrier with `𝟘 = phantom`. A 4-point carrier changes T1, the relation `≈` and the phantom part of T2. These changes are decisions of the owner.

== Stage 3

[[DC-3.1]]
=== DC-3.1: the source calculus is a small fragment of System FC

*Choice.* The source calculus (`Wager.FC`) follows Breitner, Eisenberg, Peyton Jones and Weirich, "Safe Zero-cost Coercions for Haskell". It has:

* base types, functions, pairs and sums;
* newtypes with no parameter and newtypes with one parameter, each with a declared role;
* total closed type-level functions with one argument;
* coercions at the three roles, with reflexivity, symmetry, transitivity, the rule from nominal to representational, the phantom rule, role-gated congruence, the newtype rules and the rules of the type-level functions;
* terms with `cast`, and `coerce` as the function `λx. cast γ x`;
* erasure into an untyped calculus.

*Limits.* Each limit makes the fragment smaller, so each limit makes claim W weaker.

* A type is closed. A term has no type variable, and there is no `∀`.
* A newtype has 0 parameters or 1 parameter. A type-level function has 1 argument.
* The data types are the function, the pair and the sum. Their parameters are representational. A signature cannot declare a data type.
* The constructor of each newtype is visible. There is no abstract type.
* There is no decomposition rule (`nth`), no coercion between polymorphic types and no coercion variable.
* A source term has no grade. System FC has no grades.

[[DC-3.2]]
=== DC-3.2: recursion is kept out by construction

*Choice.* The body of a newtype with one parameter is a `Body`: the parameter, a base type, a function, a pair, a sum, or a type-level function on a body.
A body cannot mention a declared newtype. The representation of a newtype with no parameter is an erased type.

*Reason.* The task says: keep recursion out. With this choice the functions `ev` (nominal value) and `er` (erased type) are structurally recursive. No termination argument is needed.

*Consequence 1.* Role inference (`roleOf`) is a structural function. In a body, the role phantom means "the parameter does not occur".
The rule for a type-level function is `nominal · r` with the lawful table: a parameter that does not occur below the function stays phantom.
`Source-Role-Soundness` is proved with this rule.

*Consequence 2.* The fragment cannot declare the body that separates the lawful table from the rule of GHC: a phantom newtype below a type-level function, such as `F (Tag a)`.
For that body the lawful table gives the role phantom to `a`. Phantom is wrong there: `F (Tag Int)` and `F (Tag Bool)` are different types (`Wager.Examples.Stage3.Nominal-Soundness-Examples.f-sees-phantom`).
A larger fragment with such bodies must use another inference rule. Stage 3 proves nothing about such a body.
The coercion rules of this fragment do have the rule of GHC for a newtype (DC-3.3).

*Alternative.* A list of declarations in which each body can mention the earlier newtypes. This is more faithful and much larger. It was not built.

[[DC-3.3]]
=== DC-3.3: one coercion relation with a role index

*Choice.* `Co r τ σ` (`Wager.FC.Coercion`) has the role `r` as an index.
The congruence rule for a newtype `N` has a premise at the role `mulG r (role N)`. `mulG` is the GHC composition table of T1.

*Reason.* This is the rule of Breitner et al.: at the role nominal the arguments are nominally equal, at the role representational the arguments are equal at the declared role, at the role phantom there is no condition.
The entry `nominal · phantom = nominal` says that a newtype is generative: `Tag Int` and `Tag Bool` are different types, also when the parameter of `Tag` is phantom.

*Note.* `Co` is a relation of the source calculus. The target calculus does not have it (`RELATION-LEDGER.adoc`, entry R14).

[[DC-3.4]]
=== DC-3.4: type-level functions look at the head of the argument

*Choice.* A source type-level function has the same form as a target primitive (DC-1.1): one equation for each head.
For a newtype with one parameter, the right side is a base type, or another function on the PARAMETER of the newtype (`F (N τ) = G τ`).

*Reason.* A closed type family of GHC can match on the argument of a type constructor. The form also keeps each function total.

*Difference from the target.* A target primitive on `capp c A` can look at `A`. In the planned translation of Stage 4, `A` is the representation of the newtype, not its parameter.
Stage 4 must show what this difference costs.

[[DC-3.5]]
=== DC-3.5: source terms are typed by construction

*Choice.* `STm Γ τ` (`Wager.FC.Term`) is the set of the terms of the type τ. There is no separate typing relation for source terms.
`cast γ e` needs a coercion `γ : Co rep τ σ`. The constructor and the destructor of a newtype are casts along the newtype rule.

*Reason.* A program with a wrong `coerce` is then not a term. "The source calculus rejects the program" means: the type of its terms has no inhabitant of that form, or the coercion type is empty (`¬ Co rep τ σ`).

[[DC-3.6]]
=== DC-3.6: the erasure semantics

*Choice.* `Wager.Erased.Untyped` has untyped terms, big-step call-by-value evaluation with closures, erased types (a base type, a function, a pair, a sum) and a typing of untyped terms with erased types.
The erasure of a source term (`eraseTm`) removes each cast. No other change is made.

*Reason.* The task asks for an erasure semantics in which coercions vanish. A cast vanishes by the definition of `eraseTm`, and `coerce` erases to `λx. x`.
The module does not depend on the source calculus. Stage 4 can erase the target calculus into the same untyped calculus and compare the two results there.

*Not proved here.* Stage 3 does not prove that a typed untyped term evaluates to a value of its erased type. It proves that erasure preserves typing (`Wager.Proofs.erasure-preserves-typing`).

== Stage 4

[[DC-4.1]]
=== DC-4.1: a newtype is a trope state on its representation, and a state scheme gives the number of states

*Choice.* The translation (`Wager.Trans`) makes the source type `N τ` the target type `A@s`: the carrier `A` is the translation of the representation of `N τ`, and `s` is a state.
A state scheme (`Wager.Trans.Scheme.StateScheme`) says which state. The state of `N τ` is the pair of `N` and an index. The index keeps what a type-level function can see of the argument τ.

Two schemes exist:

* `rowScheme`: the index is the row of the results of all the type-level functions on `N τ`. It exists for each source signature.
* `twoState`: there is one index. The newtype is a two-state trope (raw, wrapped), as in Stage 2. It exists when no type-level function looks at the argument of a newtype.

*Reason.* Stage 2 made a newtype a two-state trope. This is not enough for a newtype with a phantom parameter and a function that looks at that parameter (`Wager.Proofs.no-two-state-translation`).
`Tag Int` and `Tag Bool` have one representation, and the function tells them apart. They need two states of one carrier.

*Finite state sets.* Document 07 says that a trope has a finite set of states. The index type of the row scheme is `Fam → Base`.
It is finite when the signature has a finite number of functions and of base types. Agda did not check this sentence. The Agda signature type has no finiteness condition.

*Limit that this result depends on.* The result of a type-level function is a base type (DC-1.1, DC-3.4). A function that returns a part of its argument, such as `F (Tag a) = a`, is outside the fragment.
For such a function a row has no finite bound. This development proves nothing about it.

[[DC-4.2]]
=== DC-4.2: the target signature of the translation

*Choice.* `Wager.Trans.Target` builds the target signature from the source signature and the state scheme:

* the base types and the literals of the source;
* one state for each newtype with no parameter, and one state for each newtype with a parameter and each index. Each state has the grade representational;
* one primitive for each type-level function. Each primitive has the grade nominal. On a state, a primitive reads its result from the index. It does not look at the carrier.

A function type `τ → σ` becomes `arr 𝟙 (T τ) (T σ)`.

*Consequence.* The target signature respects its declared grades (`Wager.Proofs.target-signature-valid`). The hypothesis `Valid` of T2 thus holds for each signature that the translation gives.
No state has a phantom parameter. A phantom parameter of the source is not a type argument in the target: it is in the name of the state.

[[DC-4.3]]
=== DC-4.3: the trope operations are wrap and unwrap, for each instance

*Choice.* The term signature has two operations for each instance of a newtype: `wrap : A → A@s` and `unwrap : A@s → A`.

*Reason.* The carrier of an operation is a closed type (DC-1.4). An operation for each instance is the form of one polymorphic operation in a calculus with no type variable in terms.
The set of operations is thus not finite. Document 07 says that the set of API operations of a trope is finite. This development gives no finite bound for the operations.

[[DC-4.4]]
=== DC-4.4: a coercion is a pair of term transformers

*Choice.* `Wager.Trans.Coercion.coI` translates a coercion to a pair of transformers `Tm n → Tm n` (forwards, backwards). The blocks are:

* wrap and unwrap (the newtype rules);
* the map of a function, of a pair and of a sum (congruence);
* unwrap, the map of the body, wrap (congruence for a newtype);
* composition (transitivity), exchange of the two directions (symmetry), and the identity.

A nominal coercion is the identity transformer. Its typing uses rule `t-conv`, because the two translated types are convertible (`Wager.Trans.Nominal.nominal-defeq`).
`coerceT γ` is the function `λx. (transformer of γ) x`. The translation of `cast γ e` is the transformer of γ on the translation of `e`.

*No cast.* The target has no cast judgement and no cast term. Each transformer is built from the term formers of Stage 1.

*Detail.* The map of a function is `(λf. λx. g (f (h x))) t`. It keeps a β-redex, so that `t` is not moved under a binder.

*Lemma that Stage 5 states as a theorem.* `nominal-defeq` is the content of T6. Stage 4 needs it for the typing of a cast, so its proof is in Stage 4. Stage 5 puts the statement of T6 in `Statements.agda`.

[[DC-4.5]]
=== DC-4.5: which grade algebra types the translation

*Choice.* Two results, with two conditions:

* A translated coercion is typed in EACH grade algebra (`Wager.Proofs.coercion-is-a-term`). It uses each variable one time, and each binder has the grade 𝟙.
* A translated program is typed in each grade algebra in which the grade 𝟙 is unrestricted: `𝟘 ≤ 𝟙` and `𝟙 + 𝟙 ≤ 𝟙` (`Wager.Proofs.t5-typing`). The one-point algebra `Wager.Grade.Trivial` is an example.

*Reason.* System FC has no usage discipline: a source term can drop a variable and can use it two times.
The rules of Stage 1 bind the two components of a pair and the variable of a `case` branch at the grade 𝟙, as the anytype checker does. A source term can drop a component. Thus 𝟙 itself must allow this.

*Consequence.* In the algebra `Affine` (systemet order) the grade 1 is linear. The translation of a source function that drops its argument has no type there (`Wager.Examples.Stage4.Coercions-In-Affine.const-rejected`).
The two conditions name the grades 𝟘 and 𝟙 only. They are hypotheses of a theorem. They are not side conditions of a rule.

[[DC-4.6]]
=== DC-4.6: observational equality is a logical relation on untyped values

*Choice.* `Wager.Erased.LogRel.𝒱 a` relates two untyped values at the erased type `a`: one literal at a base type, related components for a pair, one injection and related contents for a sum, and for two function values related results on related arguments.
T3 and the behaviour part of T5 are stated with it. On a first-order type (no function) the relation is equality of values.

*The erasure of the target.* `eraseT` removes each trope transition and each type annotation. No other change is made.

*Not proved here.* This development does not define contextual equivalence, and it does not prove that `𝒱` agrees with it.
It also does not prove that the reduction of the target (`_⟶_`, Stage 1) agrees with the evaluation of the erased target term.

[[DC-4.7]]
=== DC-4.7: the form of the role correspondence

*Choice.* The body of a newtype `N` is the type-level function `bodyFun N g` of the target, with the grade `g` for its parameter.
The correspondence says: graded kinding, with the lawful role table, accepts `g` exactly when the inferred source role is at most `g` (`Wager.Proofs.role-correspondence`).

*Reason.* The task says: "the source assigns the role ρ to a parameter if and only if the target kinding assigns the matching grade".
Kinding has a subusage rule, so it accepts each grade above the least one. "The matching grade" is thus the least accepted grade.

*Limit.* The correspondence is about the body. In the translation the newtype `N` itself is not a type-level function of the target, because the state depends on the index of the argument.

[[DC-4.8]]
=== DC-4.8: what "no translation" means

*Choice.* `Wager.Trans.TwoState.Translation` says what a translation of types must keep: a nominal coercion becomes conversion, a type-level function becomes a type-level function of the target, and two different base types stay different.
`TwoState` adds: each newtype with a parameter is one state on the translation of its representation.
`Wager.Proofs.no-two-state-translation` says that the signature `taggedS rep` has no such translation, into any target signature.

*Reason.* "This program has no translation" needs a definition of "translation". The three conditions are properties that claim W asks for. The fourth condition is the form of Stage 2.
The translation with the row scheme meets the three conditions (`Wager.Proofs.row-translation-exists`), so the conditions are not empty.
