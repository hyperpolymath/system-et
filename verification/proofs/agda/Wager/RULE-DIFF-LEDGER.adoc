= Wager: rule-diff ledger
Status: Stage 1. *The ledger is empty.*
:toc: left
:sectnums:

This file lists each typing rule or kinding rule that names a grade element other than `0` and `1`, or that has a side condition for one algebra.
Each entry counts against the wager.

== Entries

None.

== Evidence

The evidence is structural, and Agda checks it.

* `Wager.L2.Typing` is a module with the parameter `ops : GradeOps (Sig.TG S)`. The carrier is abstract.
  A rule of the module can name a grade only as `𝟘`, as `𝟙`, or as a variable.
* `Wager.L1.Kinding` is a module with the parameter `K : GradeOps (Sig.KG S)`. The same argument holds.
* The two modules take the operations only. They do not take the laws, and they cannot assume a law of one algebra.

== Grades that come from the signature

`cgrade` and `pgrade` give the parameter grade of a constant and of a primitive.
They are data of the signature, not of a rule.
A later stage chooses these entries for a specific algebra.
If a theorem then needs a condition on the entries, `VERDICT.adoc` records the condition with the class "signature primitive".
